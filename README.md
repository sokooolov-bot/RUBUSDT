# RUBUSDT — Учёт обмена RUB ↔ USDT

Локальное приложение для личного учёта операций RUB ↔ USDT.

Технологии: React + TypeScript + Vite, Tailwind CSS, Dexie (IndexedDB), decimal.js, Recharts.


## Как запустить локально (MacBook)

1. Установите Node.js (рекомендуется v18+). Скачайте с https://nodejs.org или установите через Homebrew:

   brew install node

2. Клонируйте репозиторий (вам нужен доступ к приватному репозиторию `sokooolov-bot/RUBUSDT`):

   git clone https://github.com/sokooolov-bot/RUBUSDT.git
   cd RUBUSDT

3. Установите зависимости:

   npm install

4. Запустите dev-сервер:

   npm run dev

5. Откройте в браузере: http://localhost:5173


## Тесты

Запустить тесты:

npm run test


## Экспорт/импорт

- Настройки → Экспорт в JSON / Импорт JSON
- Кнопка загрузки демоданных в Настройках


## Как создать репозиторий и загрузить код (шаги для новичка)

1. Откройте github.com и войдите в аккаунт.
2. Нажмите «New repository» и введите имя (например, `RUBUSDT`). Выберите Private или Public.
3. На вашем компьютере откройте Терминал.
4. Если репозиторий пустой, клонируйте его: `git clone https://github.com/<ваш-логин>/RUBUSDT.git`.
5. Скопируйте в папку репозитория файлы проекта (или распакуйте архив).
6. Выполните:

   git add .
   git commit -m "Initial project"
   git push origin main

7. На GitHub код появится в репозитории.


## Что реализовано

- Хранилище (IndexedDB через Dexie)
- CRUD операций и карт
- Покупки создают партии (batches)
- FIFO-алгоритм для расчёта себестоимости (тесты)
- Экспорт/импорт JSON, демоданные
